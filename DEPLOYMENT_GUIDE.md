# Oracle ARM Deployment Guide

This guide walks you through deploying the Poetry RAG project to an Oracle Cloud Always Free ARM (Ampere A1) instance.

## 1. Create an Oracle Cloud Account & Server from Scratch

If you have never used Oracle Cloud before, follow these steps exactly. Oracle offers a very generous "Always Free" tier, which is perfect for this.

**A. Registration**
1. Go to [Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/) and click **Start for free**.
2. Fill out your details. *Note: They will ask for a credit card to verify you are a real person, but they will **not** charge you unless you manually upgrade to a paid account later.*
3. Verify your email and complete the sign-up. It may take a few minutes for your account to be provisioned.

**B. Creating the Virtual Machine (The Server)**
1. Once logged into the Oracle Cloud Console dashboard, look for **"Create a VM instance"** and click it.
2. Name your instance (e.g., `poetry-rag-server`).
3. Scroll down to **Image and shape**:
   - Click **Edit**.
   - Under **Image**, click "Change image". Select **Ubuntu** (choose version 24.04 or 22.04).
   - Under **Shape**, click "Change shape". Select **Virtual machine**, then select **Ampere** (this is the ARM CPU), and check the box for **VM.Standard.A1.Flex**.
   - A slider will appear for CPU and RAM. Max them out to the free limits: **4 OCPUs** and **24 GB Memory**. Click **Select shape**.
4. Scroll down to **Networking**:
   - Leave it on default. It will automatically create a new Virtual Cloud Network (VCN) and a public subnet for you. Make sure "Assign a public IPv4 address" is checked.
5. Scroll down to **Add SSH keys**:
   - This is how you will securely log in to your server instead of using a password.
   - Select **"Generate a key pair for me"**.
   - **CRITICAL:** Click **Save private key**. A `.key` or `.pem` file will download to your computer. Put this file somewhere safe (like `C:\Users\braaj\.ssh\oracle-key.key`). You *cannot* download this again later!
6. Scroll to the bottom and click **Create**.

**C. Getting Your IP Address**
1. The server will say "PROVISIONING" (yellow square) and then turn to "RUNNING" (green square).
2. Once running, look on the right side of the screen under **Instance access**.
3. Copy the **Public IP address**.

**D. Testing the Connection**
1. Open PowerShell on your Windows machine.
2. Run the SSH command using the private key you downloaded:
   ```bash
   # Replace the path with where you actually saved the key, and the IP with your server's IP
   ssh -i C:\path\to\your\oracle-key.key ubuntu@<YOUR_PUBLIC_IP>
   ```
3. Type `yes` when it asks if you want to continue connecting. You are now inside your cloud server! Type `exit` to return to your local machine.
## 2. Transfer the Code
From your Windows machine, upload the lightweight project code using `scp` or `rsync` (no need to transfer the 5.6GB model or database, the server will build them automatically!):

```bash
scp -i path/to/your-key.pem -r d:\Projects\poetry-rag ubuntu@<your-oracle-ip>:~/poetry-rag
```

## 3. Install Docker on Oracle
SSH into your Oracle instance:
```bash
ssh -i path/to/your-key.pem ubuntu@<your-oracle-ip>
```
Install Docker:
```bash
sudo apt update
sudo apt install -y docker.io docker-compose-v2
sudo usermod -aG docker $USER
```
*Log out and log back in for the Docker group permissions to take effect.*

## 4. Build and Run
Navigate to your project directory and start the stack:
```bash
cd ~/poetry-rag
docker compose up --build -d
```
*Note: The first run will take a while! It will natively compile `llama.cpp` for ARM, download the 5.6GB model from Hugging Face, and embed the 3.4 million verse corpus into LanceDB. Check the logs with `docker compose logs -f web` to watch the progress.*

## 5. Access the Web App
If you check the logs of the `cloudflared` container:
```bash
docker compose logs cloudflared
```
You will see a URL generated by Cloudflare (e.g., `https://something-random.trycloudflare.com`). 
Click that link! You can share it with anyone, and they can use the app without you needing to open any ports on the Oracle Virtual Cloud Network.

*Tip: If you want a persistent custom domain, you can set up a named Cloudflare tunnel later.*
